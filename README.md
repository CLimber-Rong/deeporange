# DeepOrange（橙度探索）

DeepOrange 是“AI 智能车虚实融合挑战赛”橙子识别题的数据准备项目。它把本地图片整理成浏览器端“识物工坊”可使用的**整图二分类**训练集：`橙子/` 和 `非橙子/`。训练时使用 MobileNet α=0.5；柠檬、乒乓球、橙色球等都属于「非橙子」。

## 开始使用

需要 Windows 和 Python 3.10 或更新版本。先在项目根目录安装依赖：

```powershell
python -m pip install Pillow numpy
```

然后双击 **`生成数据集.bat`**。它会依次运行混淆增强、数据整理和视觉去重。也可以在终端中手动执行：

```powershell
python obfuscate.py
python combine.py
```

处理完成后，将 `橙子/` 和 `非橙子/` 分别作为两个训练类别导入“识物工坊”。如果发现同一图片同时出现在两个类别中，脚本会暂停并询问：输入 `P` 删除橙子侧、`N` 删除非橙子侧，或 `A` 两侧都删除。

也可以用 [本地训练器](本地训练/README.md) 在 Windows 10 本地训练。双击 `本地训练/train.bat` 打开图形界面；它会优先使用项目根目录现有的两个训练类别。训练器默认选择原版，但原版会划出约 15% 图片作验证。若要保持全部样本用于训练，将 `本地训练/trainer_config.json` 中的 `trainer` 改为 `original_full_data`，保存后重启训练器。导出的模型可在训练器「测试」页先用独立图片检查；官网上传兼容性仍需实际验证。

> **重跑会清空 `橙子/` 和 `非橙子/` 中的旧图片，再完整重建。** 请勿把唯一原件或手工精选图放在这两个目录。目录中若有非图片文件、子目录或链接，程序会先停止，不会清空。

## 数据从哪里来

| 位置 | 用途 |
| --- | --- |
| `待变换数据/` | 白底橙子原图；稳定选取 140 张，生成白底变换图。 |
| `待混淆数据/`、`背景/` | 白底橙子与背景图；排除 4 张已确认破损原图后，生成 696 张换背景图。 |
| `数据源/橙子数据源/` | 自然场景橙子照片，以及两个脚本生成的橙子来源目录。 |
| `数据源/非橙子数据源/manifest.json` | 指定从 `总资源/` 的各来源目录选取多少张负样本。 |
| `橙子/`、`非橙子/` | 可直接用于训练的最终输出。 |
| `验证集/`、`测试集/` | 独立评估素材；生成脚本不会读取，也不应混入训练来源。 |
| `爬虫/` | 临时收集区；图片审查并转入正式来源后才参与生成。 |

当前配置计划取用橙子 1006 张、非橙子 1015 张。2026-09-26 最近一次生成的输出分别为 **1001 张**和 **1011 张**；差异来自清洗和去重。这只是当前快照，后续以重跑结果为准。具体配额及选图原则见 [AGENTS.md](AGENTS.md)。

大量图片目录被 `.gitignore` 排除，**只复制代码仓库并不能重建数据集**：还需要本地的原图、背景和资源目录。请保留 `总资源/`、`待变换数据/`、`待混淆数据/` 中的原始素材。`obfuscate.py` 会规范化 `背景/` 下的图片文件名，并缓存抠图遮罩到 `.obfuscate_cache/`；缓存可以删除，下次会自动重建。

## 调整选图

- **非橙子配额**：编辑 `数据源/非橙子数据源/manifest.json`。每个来源只写项目根目录相对 `path` 和正整数 `count`；脚本按固定种子稳定选图。增加图片后，应检查类别、可读性、近重复及中心裁剪效果，再调整配额。
- **橙子合成**：将新背景加入 `背景/`；单张背景最多用于 12 张成品。要排除已确认破损的待混淆源图，在 `obfuscate_exclusions.txt` 中每行写一个相对路径。
- **质量复查**：橙子与非橙子应在正方形中心裁剪后仍清楚可辨。剔除错标、明显水印遮挡主体、严重失焦和同一原图的近重复版本。正式训练前复查最终输出数量与样本质量。

当需要集中补图或审查时，可以临时在根目录建立 `requirements.md` 清单，任务完成后删除。维护脚本或调整长期配额时，按 [AGENTS.md](AGENTS.md) 同步更新项目说明。
